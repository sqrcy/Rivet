# Rivet Docs Website

This Docusaurus app contains the public documentation site for Rivet.

## Local Development

```bash
npm run start
```

## Production Build

```bash
npm run build
```

## Type Check

```bash
npm run typecheck
```

The documentation content lives in `docs/`, navigation is configured in `sidebars.ts`, and the site metadata/nav/footer are configured in `docusaurus.config.ts`.
