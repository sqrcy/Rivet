# Rivet Docs

Welcome to Rivet. These docs assume you know basic Roblox ModuleScripts, but
nothing about Rivet yet.

Rivet helps you organize Roblox code into Units. A Unit is a normal ModuleScript
that Rivet can start, connect to other Units, clean up, and expose through safe
runtime surfaces.
